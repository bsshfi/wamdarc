# wamdarc.com — موقع ومض آرك | WAMD ARC

موقع ثابت على GitHub Pages (`CNAME` = wamdarc.com). مظهران: **نهار** (فاتح، الافتراضي) و**ليل** (داكن بالقوس)، والزر أعلى الصفحة يبدّل بينهما ويحفظ الاختيار. عربي وإنجليزي بزر واحد (`?lang=en`).

## الصفحات
| المسار | الصفحة |
|---|---|
| `/` | الرئيسية: الواجهة، التطبيقات، وعدنا، التثبيت، من نحن، أسئلة، تواصل |
| `/sahm/` `/falaq/` `/khuta/` `/harf/` `/siraj/` `/nabd/` | صفحة لكل تطبيق |
| `/updates/` | جديدنا (سجل التحديثات مع فلتر لكل تطبيق) |
| `/privacy/` | سياسة الخصوصية المختصرة (والكاملة داخل كل تطبيق) |
| `/thanks.html` `/404.html` | بعد إرسال النموذج، والروابط الخاطئة |

## التعديل
**لا تعدّل ملفات HTML يدويًا** — كلها مولّدة:
1. عدّل النصوص في `build/content.py` (كل نص عربي + إنجليزي، والتطبيقات، وجديدنا).
2. شغّل `python3 build/build.py` → يكتب الصفحات و`assets/i18n.js` و`sitemap.xml`.
3. صور المشاركة (اختياري): `python3 -m http.server 8201 &` ثم `python3 build/og.py 8201`.

مجلد `build` مستثنى من النشر في `_config.yml`.

## الملفات
- `assets/site.css` التصميم، `assets/site.js` المظهر واللغة والقائمة والقوس والنموذج والفلتر
- `assets/<app>/` أيقونة التطبيق ولقطاته، `assets/qr/<app>.svg` رموز QR (تستخدمها لوحة الإدارة)
- `assets/og-*.png` صور المشاركة في واتساب وإكس
- `assets/wamd-stats.js` عدّاد الاستخدام المشترك — **لا يُعدّل**

## تطبيق جديد
أضفه في `APPS` داخل `build/content.py`، وضع أيقونته ولقطاته في `assets/<app>/`، وولّد QR بـ `qrcode`، ثم ابنِ.

## نموذج التواصل
FormSubmit إلى contact@wamdarc.com، وخانة «بخصوص» تظهر في عنوان الإيميل.
