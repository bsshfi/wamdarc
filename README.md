# wamdarc.com — النسخة الثانية (هوية الشرارة والمسار)

## طريقة التحديث على GitHub
1. افتح مستودع الموقع الحالي.
2. احذف من مجلد `assets` الملفات القديمة: `mark.svg` و`wamdarc-ar.png` (اختياري، ما تضر لو بقت).
3. ارفع **محتويات** هذا المجلد واستبدل الموجود:
   - `index.html` (يستبدل القديم)
   - كل ما في مجلد `assets/`
   - `CNAME` (نفسه، لا تحذفه)
4. Commit changes — ويتحدث الموقع خلال دقيقة أو دقيقتين.

## الملفات
- `index.html` — الصفحة كاملة
- `assets/logo-stacked-on-dark.svg` — الشعار الأساسي
- `assets/logo-horizontal-on-dark.svg` — الشعار الأفقي (الهيدر والفوتر)
- `assets/mark-on-dark.svg` — الرمز وحده
- `assets/favicon.svg` — أيقونة المتصفح
- `assets/apple-touch-icon.png` — أيقونة الآيفون لما أحد يضيف الموقع للشاشة الرئيسية
- `assets/og-image.png` — الصورة اللي تطلع لما أحد يشارك الرابط في واتساب أو X

## تعديلات سريعة
- رابط سهم: ابحث عن التعليق `لربط سهم` داخل index.html وحوّل البطاقة لرابط.
- الحسابات: تيك توك @wamd.arc، وباقي الحسابات wamdarc.
