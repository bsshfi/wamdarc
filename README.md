# موقع وَمْض آرك — wamdarc.com

صفحة رئيسية ثابتة (HTML واحد) تُستضاف مجانًا على GitHub Pages.

## الملفات
- `index.html` — الصفحة كاملة (التصميم والمحتوى)
- `assets/mark.svg` — رمز البوابة
- `assets/favicon.svg` — أيقونة المتصفح
- `assets/wamdarc-ar.png` — الاسم العربي بخط ثمانية
- `CNAME` — يربط الموقع بدومين wamdarc.com (لا تحذفه)

## خطوات النشر
1. أنشئ مستودع جديد في GitHub (مثلاً `wamdarc-site`) واجعله Public.
2. ارفع كل الملفات كما هي (Add file ← Upload files).
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** / **root** ← Save.
4. في نفس الصفحة، Custom domain: اكتب `wamdarc.com` واحفظ.

## إعداد الدومين (عند الشركة اللي اشتريت منها)
أضف هذه السجلات في إعدادات DNS:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | اسم-حسابك.github.io |

بعد ما يشتغل الدومين (من دقائق إلى ٢٤ ساعة)، فعّل **Enforce HTTPS** في صفحة Pages.

## تعديلات سريعة
- رابط تطبيق سهم: ابحث عن `<a class="product" href="#">` وضع رابط التطبيق مكان `#`.
- الخدمات والنصوص: كلها داخل `index.html` وتقدر تعدّلها مباشرة من GitHub.
