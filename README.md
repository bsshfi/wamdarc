# wamdarc.com — النسخة الرابعة

## الصفحات
- `index.html` الرئيسية: الواجهة، تطبيقاتنا، وعدنا، طريقة التثبيت، من نحن، تواصل معنا
- `sahm/` و `falaq/` و `khuta/` صفحة لكل تطبيق (wamdarc.com/sahm وهكذا)
- `privacy/` سياسة الخصوصية
- `thanks.html` بعد إرسال النموذج، و `404.html` للروابط الخاطئة
- `sitemap.xml` و `robots.txt` لمحركات البحث

## الرفع على GitHub
ارفع **كل محتويات** هذا المجلد على مستودع الموقع واستبدل الموجود، مع المجلدات:
`assets` و `sahm` و `falaq` و `khuta` و `privacy`. لا تحذف `CNAME`.

## الملفات المشتركة
- `assets/site.css` التصميم لكل الصفحات
- `assets/i18n.js` كل النصوص بالعربي والإنجليزي
- `assets/site.js` تبديل اللغة، النموذج، رموز QR
- `assets/hero.webp` صورة الواجهة (و `hero-sm.webp` للجوال)
- `assets/og-*.png` الصور اللي تطلع لما تشارك الرابط في واتساب وإكس

## نموذج التواصل
نفس FormSubmit السابق (مفعّل). الجديد: خانة «بخصوص» وتظهر في عنوان الإيميل،
مثلاً: «رسالة جديدة من wamdarc.com — Falaq».

## بعد الرفع (اختياري لكن مفيد)
سجّل الموقع في Google Search Console وأرسل له `https://wamdarc.com/sitemap.xml`.
